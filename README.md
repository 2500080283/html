## 📖 Overview

This repository contains a comprehensive suite of Front-End Development (FED) laboratory experiments, assignments, and interactive web pages built using modern HTML5 standards, CSS3 styling techniques, and client-side JavaScript.

All exercises are fully accessible, W3C compliant, and organized under an interactive dashboard entrypoint at `index.html`.

---

## 🚀 Lab Experiments & Features

| File | Title | Description | Key Technologies |
| :--- | :--- | :--- | :--- |
| [`index.html`](index.html) | **Lab Hub & Portfolio** | Central launchpad for all experiments with student information and tag reference | Flexbox, Responsive Grid, Semantic Header |
| [`USERPAGE.html`](USERPAGE.html) | **Student Profile & Registration** | Interactive registration portal with real-time validation, DOB-to-age calculator, and review modal | JavaScript Validation, Event Listeners, DOM Manipulation |
| [`tabletags.html`](tabletags.html) | **Student Information Table** | Tabular layout displaying student roll numbers, scores, courses, and KL University emblem | Table Semantics (`thead`, `tbody`, `tr`, `th`, `td`) |
| [`forms.html`](forms.html) | **HTML Form Controls** | Complete demonstration of input types, fieldset groups, legends, dropdowns, and validation states | HTML5 Input Types, CSS Form Styling |
| [`sechmatic.html`](sechmatic.html) | **Semantic Web Architecture** | Modern page layout demonstrating HTML5 semantic structural tags | `<header>`, `<nav>`, `<aside>`, `<main>`, `<article>`, `<details>` |
| [`sechematic-ai.html`](sechematic-ai.html) | **AI & Web Portfolio** | Glassmorphism-inspired developer portfolio layout | Modern CSS Variables, Backdrop Filters, Grid Layout |
| [`all-tags.html`](all-tags.html) | **All HTML5 Elements** | Comprehensive reference dictionary displaying HTML5 elements with live demos | Canvas, Datalist, Progress, Media, Blockquote |
| [`image.html`](image.html) | **Multimedia Gallery** | Responsive media gallery embedding images, audio player, and video player | `<figure>`, `<figcaption>`, `<audio>`, `<video>` |
| [`hyperlink.html`](hyperlink.html) | **Web Resource Directory** | Curated external resource directory with card previews | Anchor tags, `target="_blank"`, `rel="noopener"` |
| [`list.html`](list.html) | **HTML Lists Reference** | Detailed breakdown of ordered, unordered, definition, and nested hierarchical lists | `<ol>`, `<ul>`, `<dl>`, `<dt>`, `<dd>` |
| [`propose.html`](propose.html) | **Interactive Card Experience** | Animated greeting card with customizable recipient name and clipboard sharing | CSS Keyframe Animations, Web Share API |
| [`USERPAGE--form.html`](USERPAGE--form.html) | **Static User Form** | Pure static HTML form implementation for structural inspection | Basic HTML Form Controls |

## 🛠️ Tech Stack & Standards

- **Markup**: Semantic HTML5 (W3C standard compliance)
- **Styling**: Vanilla CSS3 (Custom properties, Flexbox, Grid, Glassmorphism, Responsive Media Queries)
- **Scripting**: Vanilla JavaScript (ES6+ standard)
- **Assets**: Scalable Vector Graphics (`KL_University_logo.svg`) and optimized media assets
- **Hosting**: Deployed on Vercel with automatic CI/CD deployment
