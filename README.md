## 📖 Overview

This repository contains a comprehensive suite of Front-End Development (FED) laboratory experiments, assignments, and interactive web pages with a **Node.js + Express REST API backend** for student registration and form submission handling.

---

## 📡 REST API Reference

Runs on `http://localhost:3000`:

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/api/health` | Backend status check |
| `GET` | `/api/students` | Retrieve all registered student profiles |
| `POST` | `/api/register` | Register student profile into database (`data/registrations.json`) |
| `POST` | `/api/contact` | Process inquiries from form controls |

## 🚀 Running the Full-Stack Server

```bash
# Clone the repository
git clone https://github.com/2500080283/html.git

# Navigate to the folder
cd html

# Install dependencies
npm install

# Start Express server
npm start
```

Access at **`http://localhost:3000`**
